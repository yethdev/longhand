# Longhand

Longhand is a closed-source VS Code extension for local inline code completion. Its model runs on your computer.

- [Model downloads and license](https://huggingface.co/yethdev/longhand-1.7b-gguf/tree/main)
- [Report a bug or request a feature](https://github.com/yethdev/longhand/issues)
- [Install Longhand from Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=longhand.longhand)
